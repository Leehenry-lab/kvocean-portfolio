Problem

분기마다 반복되는, 재무정보 입력 업무

VC 기획관리팀은 분기마다 140여 개 피투자사의 재무제표를 입력하고 관리해야 합니다. 그 데이터를 활용해 런웨이·EBITDA 등과 같은 평가 자료를 만듭니다. 입력은 수기로 이뤄지고, OCR로 뽑은 자료는 정확도 문제가 있었습니다.

검증 없는 OCR

OCR이 계정명을 깨뜨리고 부호를 놓쳐도 걸러줄 장치가 없어, 데이터 신뢰성에 문제가 생겼습니다.

주요 항목만 데이터화

재무제표의 모든 항목을 데이터로 관리하기 어려워, 자산·부채·자본 같은 주요 항목만 관리해 왔습니다. 세부 계정 단위의 분석은 매번 원본 파일을 다시 열어야 가능했습니다.

Pipeline

원본 재무제표에서 구글시트까지, 끊기지 않는 한 줄

핵심 설계는 "통과율 100%인 데이터만 저장된다"는 게이트입니다. 합계 검증·분류 매칭·부호 검증을 모두 통과해야 누적 DB에 들어가고, 저장과 동시에 시트로 동기화됩니다.

INPUT

재무제표 원본

회사마다 다른 PDF · 엑셀

EXTRACT

OCR · AI 추출

3행 텍스트(섹션·계정명·값) + 멀티에이전트 2차 보정

VALIDATE

검증 엔진

합계 · 분류 매칭 · 부호 검증, 통과율 100%만 통과

STORE

누적 DB

회사/분기 단위 갱신 · 휴지통 복구

OUTPUT

지표 · 시트

런웨이 · EBITDA 등 자동 산출, 구글시트 동기화

kvocean.kakao.vc — 3-1. 수식
TRANSPARENCY

수식을 화면에 공개

모든 지표의 계산식을 앱 안에서 열람하게 했습니다. "이 숫자 어떻게 나온 거예요?"라는 질문에 수식 탭 링크 하나로 답합니다. 계산 수정 논의도 이 목록 기준으로 합니다.

kvocean.kakao.vc — 4. 분류DB
TAXONOMY

계정트리 · 정합성 점검

재무제표 전 항목을 LV5까지 세분화한 계정 분류 트리를 구글시트와 동기화하고, 트리에 없는 OCR 계정(미분류)을 추려 사람이 분류하게 합니다. 저장된 전체 데이터를 현재 규칙으로 재검증하는 정합성 점검도 이 탭에 있습니다.

kvocean.kakao.vc/admin

직책 안내

최종 관리자

모든 기능에 접근 가능(데이터 삭제 포함). 본인 계정은 다른 관리자가 수정·삭제할 수 없음(보호됨).

관리자

계정 추가·권한변경·삭제 가능 (최종 관리자 계정 제외). 앱 내 모든 탭 수정 가능. 데이터 삭제는 최종 관리자만 가능.

매니저

모든 탭 접근(조회) 가능. 단 1-1, 3-1, 4번 탭은 조회 전용(규칙 수정·시트 동기화·미분류 삭제 불가), 데이터 삭제 불가.

ACCESS CONTROL

화이트리스트 · 3단계 권한

Google OAuth 위에 화이트리스트와 매니저/관리자/최종 관리자 3단계 역할을 얹었습니다. 미승인 계정은 접근 요청을 남기고, 관리자가 승인하면 초대 메일이 자동 발송됩니다.

Impact

기대 효과

  • 검증이 기본값이 됐습니다. 통과율 100%를 못 넘는 데이터는 저장 자체가 안 되므로, 보고서에 실리는 모든 숫자에 검증 이력이 있습니다.
  • 재무제표의 모든 항목이 데이터가 됐습니다. 자산·부채·자본 같은 주요 항목만 관리하던 방식에서 벗어나, 전 계정을 LV5 세분화 체계로 데이터화해 163개사 · 778건의 단일 누적 DB로 모았습니다.
  • 지표 산출이 버튼 한 번이 됐습니다. 런웨이 · EBITDA · 월 평균 지출액 등과 같은 지표가 수식 공개된 엔진에서 자동 계산되고, 구글시트 · 엑셀로 바로 나갑니다.
  • 사람은 판단에만 집중합니다. 오타 제안 · 미분류 추출 · AI 보정은 후보를 만들 뿐, 확정은 항상 사람이 합니다. 검증 단계를 대체하지 않는 자동화가 원칙입니다.
